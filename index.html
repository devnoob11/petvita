📦 Exportar Backup

Gera um arquivo .petvita-backup contendo todos os seus pets, eventos e laudos anexados. Salve em local seguro (nuvem, HD externo, etc.).

⚠️ Os dados do PetVita ficam apenas neste navegador (IndexedDB). Limpar cache ou cookies pode apagá-los permanentemente. Faça backup regularmente!

📂 Importar / Restaurar Backup

Selecione um arquivo .petvita-backup exportado anteriormente. Atenção: a importação adiciona os dados ao existente (não apaga o que já está no app).

ℹ️ Onde ficam os dados?

Todos os dados (incluindo fotos dos pets e laudos de exames em PDF ou imagem) são armazenados no IndexedDB do seu navegador — uma base de dados local, diretamente no seu computador ou celular. Nenhuma informação é enviada para a internet.

O IndexedDB tem capacidade muito maior que o localStorage e suporta arquivos binários (PDFs, imagens), por isso é usado aqui. Os dados persistem entre sessões, mas podem ser apagados se você limpar o cache do navegador.
